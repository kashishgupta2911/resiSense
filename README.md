# resiSense

resiSense is a machine-learning based recommendation system built to help newcomers in Edmonton find the most livable neighbourhoods based on safety, accessibility, affordability, and amenities.
Whether you're looking for areas close to your University, with low crime rates, or transit options - resiSense gives you a personalized neighbourhood livability score, to make your search smarter and easier
